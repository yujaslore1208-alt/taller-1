Etiquetas HTML

GLOSARIO

1. Nombre: HTML
Definición: Es un lenguaje de marcado utilizado para crear y estructurar páginas web.
Función: Organizar todo el contenido de una página web, como textos, imágenes, enlaces y títulos.
2. Nombre: HEAD
Definición: Es una etiqueta que contiene información sobre el documento HTML que no se muestra directamente en el contenido de la página.
Función: Incluir metadatos, el título de la página y enlaces a archivos de estilos.
3. Nombre: TITLE
Definición: Es una etiqueta que permite establecer el título de una página web.
Función: Mostrar el nombre de la página en la pestaña del navegador.
4. Nombre: BODY
Definición: Es una etiqueta que contiene el contenido principal y visible de una página web.
Función: Mostrar textos, imágenes, enlaces, tablas y otros elementos que el usuario puede visualizar.
5. Nombre: H1
Definición: Es una etiqueta utilizada para definir el encabezado principal de una página o sección.
Función: Presentar el título más importante del contenido y facilitar su organización.
Nombre: P
Definición: Es una etiqueta que se utiliza para representar un párrafo de texto.
Función: Organizar la información escrita en bloques de texto para facilitar su lectura.
7. Nombre: BR
Definición: Es una etiqueta que permite insertar un salto de línea dentro de un texto.
Función: Pasar el contenido a la siguiente línea sin iniciar un nuevo párrafo.
Nombre: A
Definición: Es una etiqueta que permite crear enlaces dentro de una página web o hacia otros sitios de internet.
Función: Facilitar la navegación entre páginas, documentos y recursos digitales.
9. Nombre: IMG
Definición: Es una etiqueta que se utiliza para insertar imágenes en una página web.
Función: Mostrar fotografías, ilustraciones, logotipos y otros recursos visuales.
Nombre: DIV
Definición: Es una etiqueta que permite agrupar diferentes elementos de una página web dentro de un mismo contenedor.
Función: Organizar el contenido en secciones y facilitar la aplicación de estilos mediante CSS.
